为 Forge 1.20.1 与 NeoForge 1.21.1 同步追加中央研究所修复、两区供电、门禁、显微分析、离心分离、一次性核心档案任务及 7 种任务物品。D2 发电机修复消耗保险丝 ×1、铜锭 ×4、红石 ×4；D1 配电控制器主手普通右键切换服务区，主手空手潜行右键切换收容区。服务区供电后在 A7 领取门禁卡，完成本设施分析与分离并恢复收容区供电后，可在 F5 提交研究记录片和分离试剂，领取一次性核心档案与虚空晶奖励。

新布局接入 881 盏分区灯、40 个受管门和 42 台加工设备，保留 120 处常亮光源及 59 处紫晶表面补光。外侧开门要求供电并手持门禁卡，内侧保留手动应急。加工使用 3 个机器槽与 36 个背包槽，断电或产物槽满时暂停；设施状态、机器物品和进度随存档保存。多人共用设施进度，门禁卡按玩家领取，核心档案每座设施共用一次；材料与奖励完整检查后结算，背包放不下时不扣材料、不掉物。

新增原生两格医疗观察床、拼接等候沙发和桌面细节，保留原有 13 类储物库存与一次性战利品规则；提供 25 份可编辑家具模型，其中本轮新增 7 份。公共 Java 17 API 仍为 v1，追加只读设施状态、可关闭的事件订阅和加工配方，已有 v1 附属保持兼容；双版附属示例追加纸张复制配方，当前示例最低核心依赖为 `[0.12.0-alpha.4,)`。

新玩法适用于新生成或新施工的 layout v3，已有 alpha.3 建筑不会自动重建或绑定任务，更新不会重抽已领取的储物战利品，玩家自行放置机器不会自动绑定或取得设施供电。收容事故事件与研究所 Boss 战仍未实现。alpha.3 历史发行及附件继续保留，稳定版保持 0.11.0。

alpha.4 已完成完整双版本干净构建与 16 组原生测试，139 项必需测试通过（含两版附属各 2 项）；两版独立客户端功能场景各完成 10 张真实交互截图，共 20 张，覆盖供电、门禁、加工菜单、一次性档案奖励及医疗家具。
