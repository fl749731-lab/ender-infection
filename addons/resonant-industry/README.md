# 末影感染：共振工业

独立科技附属，当前发行版本 **0.1.0**，本轮实现与验证目标为 **NeoForge Minecraft 1.21.1 / Java 21**，适配末影感染核心 **0.12.0-alpha.7** 及 GeckoLib。附属不内嵌主模组代码，Forge 历史工程与共享资源源保留。

已公开的 [alpha.1 下载与更新说明](https://github.com/fl749731-lab/ender-infection/releases/tag/resonant-industry-v0.1.0-alpha.1)及其配套[核心 alpha.5](https://github.com/fl749731-lab/ender-infection/releases/tag/v0.12.0-alpha.5)保留为历史版本。`resonant-industry-guide-0.1.0-alpha.1.zip` 内含首版图纸与运行图集。

首版提供三种可由玩家搭建的多方块，以及真实 FE 能源、储能、流体、物品接口、装配扳手和游戏内逐层手册。研究所探索任务与工业能量分别保存；修好旧研究所不会凭空产生工业电力。此版本没有新增工业附楼、灭菌舱、合金炉或裂隙堆，它们留待后续阶段。

## 生存起步

1. 合成**共振工业手册**（书＋紫水晶碎片）、**装配扳手**、控制器和机器蓝图。所有外壳、端口、电缆、管道、储能箱、储液罐和泵均有生存配方。
2. 放好控制器，手持蓝图右键设置机器类型。图纸以控制器为相对原点，支持四向旋转；图纸宽×高×长包含底板和外壳。
3. 手持扳手瞄准控制器查看结构线框。青色表示对应部件正确，红色表示缺少或放错；切换建材后预览保留，远离 16 格关闭。潜行时按层轮播。
4. 按图搭完后，普通右键扳手检查成形。报错会指出所需部件及坐标；潜行右键扳手拆解成形状态。
5. 普通右键控制器打开机器面板。物品输入口接漏斗或物品管，输出口导出产物和残渣；能源口接电缆，流体输入／输出口接流体管。

| 机器 | 尺寸 | 每批材料 | 产物 | 能源／时间 |
|---|---|---|---|---|
| 燃料发电机 | 3×3×3 | 煤炭或木炭 ×1 | 电力 | 64 FE/t，持续 1600 tick |
| 生物质处理罐 | 3×4×3 | 菌丝束、孢子囊或浓缩生物质 ×1；水 1000 mB | 营养浆液 1000 mB | 16 FE/t，160 tick |
| 工业离心阵列 | 3×3×5 | 玻璃瓶 ×1；浆液 1000 mB | 分离试剂 ×1、燃料残渣 ×1 | 24 FE/t，200 tick |
| 工业离心阵列（组织） | 同上 | 原始组织样本 ×1；浆液 1000 mB | 纯化组织 ×2、燃料残渣 ×1 | 24 FE/t，240 tick |
| 工业离心阵列（复合分离） | 同上 | I1 玻璃瓶 ×2、I2 纸 ×1；流体 I1 浆液 1000 mB、I2 水 1000 mB；催化首槽煤或木炭 ×1，保留 | 分离试剂 ×2、残渣 ×1；流体 O1 回水 500 mB、O2 回浆 250 mB | 32 FE/t，240 tick |

浓缩生物质也可直接作为燃料，持续 800 tick；残渣持续 400 tick。发电机缓冲满时暂停燃烧。物品与流体在本批完成时一起扣除，电量随加工进度消耗；断电、输出满或结构区块未载入时暂停，不产生离线产量。

## 能源、液体与接口

- **铜芯电缆**：每段缓冲 4000 FE，向邻接设备传电；标准 FE 接口可以接入其他提供对应能力的模组设备。
- **储能箱**：200,000 FE；正面主动输出，其余方向输入。机器控制器内有 100,000 FE 缓冲；机器通过指定能源口接线。
- **流体管**：每段 1000 mB 缓冲，管网每 5 tick 最多传输 250 mB，支持最多 128 段的有界搜索，优先供应加工输入口。只访问已载入区块。
- **储液罐**：16,000 mB，正面主动输出；普通管道与罐不会混合不同液体。
- **取水泵**：放在水源上方，供电后每秒最多取水 1000 mB，消耗 100 FE。旁边至少两个水源时保留可再生水源，否则移除被抽取的单个水源方块。
- 用水桶或浆液桶给输入端加液，空桶从输出端或储液罐取液。每桶 1000 mB；背包无空位时拒绝从一叠空桶中取液。

控制器统一保存库存、能量、两种液体缓冲、加工进度和剩余燃烧时间；接口通过控制器身份代理库存。拆坏接口或外壳时机器停止，库存留在控制器。拆除控制器会掉落物品，液体与能量应先取出；移动整台设备前先完成加工并清空缓冲。未卸出的存量不写入掉落的控制器物品。

成形后，发电机显示发动机、散热片与排气管；处理罐显示立式玻璃罐体、搅拌轴与顶部电机；离心阵列显示卧式分段滚筒、轴承与支架。运行时对应转子旋转，处理罐可见液位。拆解后恢复逐格部件，新增机器定义仍可使用通用外壳。模型采用原生 Java 方块几何和原版材质，没有使用 Blockbench。

电缆采用细铜芯、绝缘层与设备插头；流体管用较粗管身和铜箍。只向相邻有效设备或同类管线伸出接头，选择框与碰撞体同步连接方向。

面板分别显示存电 / 容量、当前发电或耗电（FE/t）、剩余燃烧秒数、输入与输出液体名称及当前量 / 容量（mB）、加工百分比与 tick 进度。未开始配方时显示等待原因。煤炭与木炭每个总计 **102,400 FE**：64 FE/t × 1600 tick；空闲机器耗电为 0，剩余电量会保存在缓冲中。储能满时显示“燃烧暂停”，不消耗剩余燃料。

手册右键打开，可查看每台机器的逐层布局、材料数量和接口说明。

### alpha.2 多介质工艺

机器面板保留原有主输入、两个产物槽和玩家背包位置，右侧增加 I2–I6 原料槽、两个催化槽、两个额外产物槽，以及四路流体输入和四路流体输出的读数。第一批新配方为上表的复合分离；煤或木炭在该配方中作为可重复使用的工艺介质，纸在完成时消耗。

对**流体输入口或输出口潜行空手右键**，循环选择通道 1–4。各端口独立保存通道，管道和桶操作都使用该端口当前通道；默认通道 1 兼容旧机器。直接对控制器使用桶仍操作第一路，其他通道通过端口操作。更多端口可以在机器定义中布置，或在同一端口上切换通道分次加料。普通罐和单根管道仍只保存一种液体。

复合分离需要在开始时同时满足两种物品、两路流体和催化介质。加工中取走介质会暂停该配方；补回后恢复。全部产物槽和回流罐都有空间才继续加工，完成时统一扣料和提交产物。配方签名随进度保存，配方定义变化时不能借用旧进度完成新配方。旧版库存编号、第一路流体与原配方进度保留迁移。

当前已实现多原料、多流体、标签匹配、复用催化介质和优先级。催化剂失活再生、温压条件、动态数据配方重载、物品管和红石停机仍属于后续计划。

电量、液体和进度的读法，以及煤炭总量计算，见[机器面板与用电说明](docs/machine-panels.md)。

## 电动工坊（NeoForge alpha.6）

用铁、铜、红石和纸合成压板机蓝图。将蓝图用在控制器上，按手册第 13 页装配，用扳手成形。压板机是 **3×3×2** 的多方块。单个铁锭或铜锭可压成一块对应板材，每次消耗 **960 FE**，用时 80 tick。

```text
朝向北。每层上排是控制器所在的前排。

顶层 Y=1       中层 Y=0       底层 Y=-1
# G #          E C I          # # #
# # #          # R #          # O #

# 外壳  G 观察窗  E 能源口  C 控制器  I 物品输入口  R 转子  O 物品输出口
```

铜板可加工为铜线。用铁板、铜板、铜线和红石合成基础电机，再用电机、板材和玻璃板制作计量泵。相应配方会随原料解锁。

### 单次定量

计量泵后方放储液罐，前方放同朝向的实验台或化学设备。用实验台界面选好源位，泵将液体送入该位的器皿。给泵接 FE 和红石。空手右键打开计量泵面板，切换 5、10、25、50、100、250 mB 剂量。扳手右键也可循环切换。一次红石信号只送一次，关掉再开启可送下一次。精密泵额外支持 1 和 2 mB。

### 自动中和

泵与磁力搅拌台同朝向。下面按北向画出液路，五台设备放在同一区块，可用 `F3+G` 查看边界。泵可从上下接电缆，红石可从相邻位置控制。

```text
           ↑ 北
           搅拌台
碱液储液罐  计量泵  成品储液罐
           果酸储液罐
```

1. 用装有果酸浸液和碱性浸液的试剂瓶分别右键后方和左侧储液罐，把液体注入罐内。搅拌台 1 号位放空烧杯或试管，2 号位放另一个空器皿。清空固体原料槽。
2. 在计量泵面板选「自动中和」，也可潜行空手右键切换。接好电并保持红石开启。每批各取 25 mB，反应后把 50 mB 中和液送入右侧罐，两个器皿留在台上重复使用。
3. 缺试剂时保留库存。断电、关闭红石或成品罐堵塞时，已开始的批次保留进度和样品。要改回手动，先关闭泵的红石，再用搅拌台的停止按钮释放当前批次。

在普通搅拌台的样品位加入 **25 mB 蒸馏水**，放一块铜板进固体槽，通红石后用开始按钮执行泵头清洗。获得一个精密泵头和 25 mB 澄清滤液。用精密泵头升级计量泵，滤液可合批蒸馏。

## 矿物与元素（NeoForge alpha.7）

| 矿物 | 元素 | 主世界矿脉中心范围 | 最低工具 | 掉落与用途 |
|---|---|---|---|---|
| 锡石 · SnO₂ | 锡 · Sn | Y −24 到 64 | 石镐 | 粗锡矿可冶炼成锡锭，再压成锡板，用于计量泵两侧板材 |
| 闪锌矿 · ZnS | 锌 · Zn | Y −56 到 24 | 铁镐 | 粗锌矿可冶炼成锌锭，再压成锌板，用于基础电机外壳 |
| 自然硫 · S | 硫 · S | Y −40 到 48 | 石镐 | 掉落硫磺，用于制作储液罐密封圈 |

三种矿都有石头和深板岩变体，支持时运和精准采集。粗锡矿、粗锌矿以及精准采集取得的锡石矿与闪锌矿均可用熔炉或高炉冶炼。已开过的世界可以到主世界未生成过的区块找矿。矿物和金属物品的悬浮提示标出化学式或元素符号。

硫磺和黏液球可合成两份含硫胶坯。把空烧杯或试管放在加热台样品位，胶坯放进固体原料槽，通燃料后点击开始。每份胶坯在游戏内 120°C 下制成一枚硫化密封圈。用两枚密封圈、两块玻璃和两个外壳可合成两个储液罐。矿脉高度和工艺也列在手册第 15 页。

### 计量泵氧化与维护

普通和精密计量泵都会在区块加载期间老化。未密封时，每 10 分钟推进一级，依次变为轻度、中度和重度氧化。泵后方储液罐含果酸浸液时，氧化速度为四倍。外壳颜色随阶段改变，轻度和中度氧化会提高 FE 消耗，重度氧化时暂停送液及自动中和，已经装入的试剂和反应进度保留。

空手右键打开面板后，可以查看两路试剂、器皿、批次进度、成品罐、电量及停机原因。把指针移到液位条上可查看介质名称和完整容量。器皿预览旁的「打开实验台」会进入原有的操作界面。

「维护」页显示四档氧化程度、密封状态及下一阶段倒计时。安装密封圈和更换泵头会消耗背包中的对应部件，也可手持部件右键泵。密封圈阻止继续氧化。维修后恢复洁净并保留已装的密封圈。拾取后重新放置的泵会保留氧化程度和密封状态。

## 构建与验收

在仓库根目录设置 `JAVA17_HOME`、`JAVA21_HOME`，运行：

```text
python addons/resonant-industry/tools/build_dual.py --clean --gametests --clients
python addons/resonant-industry/tools/draw_blueprints.py
```

本轮 NeoForge 开发验收使用 `python addons/resonant-industry/tools/build_dual.py --loader neoforge --gametests --clients`。原生测试包括工坊自动中和、矿物生成与掉落，以及锡、锌、硫的生存用途。工坊存档检查运行三个独立服务器进程。矿物检查另在新的普通主世界核对自然矿脉。最终通过记录及绑定的核心 JAR 摘要以生成的验证文件为准。

主模组开发 JAR 会先从对应工程构建，再作为附属的编译／开发运行依赖。`common` 是 Java 17 兼容的附属公共契约；Forge 为玩法及资源源，`tools/sync_neoforge.py` 转换到 NeoForge `build/generated`，平台能力桥分别维护。请克隆完整仓库进行源码构建，不手改生成目录。

`--gametests` 包括所选版本的原生测试与真实服务器进程：在加工途中保存退出、重启并实际卸载／重载结构区块、完成两批后再次重启核对产物。`--clients` 通过原生交互包成形、插入材料、加水和取出产物，并保存手册、预览及运行实景。场地、存档和资源缓存均在 `build` 中，不使用玩家已有实例。

结果在 `build/validation/verified-builds.json`。主模组的发布门槛仍为仓库既有的完整双版验证命令；本附属与主模组分别发版。发布前运行完整核心及附属验收，再执行 `tools/package_release.py` 生成绑定 JAR 校验和的附件；该打包工具只写本地文件。显式执行 `tools/publish_prepared.py` 时，才由 qegg 上传 alpha；它使用 `qegg.toml` 的独立标签，并在运行结束后恢复核心的 qegg 元数据。

2026-11-05 本地验收：两版干净构建，各 12 项必需原生测试通过；各完成 3 次专用服务器进程和 12 张客户端截图。煤炭实际输出各为 102,400 FE，燃尽后再检查 200 tick 无新增电量。两份 JAR 的 131 项美术资源与 Forge 源一致（仅换行格式不同）；中文在 Forge、英文在 NeoForge 客户端检查。

## 给其他附属开发者

公共接口位于 `common/src/main/java/dev/hui/resonantindustry/api`。在自己的 Mod 构造阶段、共振工业构造之后注册，设置 `resonant_industry` 为必需前置。公共初始化结束后注册表冻结。

```java
IndustryApi.registerRecipe(new IndustryRecipe(
    "my_addon:slurry_books", IndustryApi.CENTRIFUGE,
    "minecraft:paper", 2, IndustryApi.SLURRY, 1000,
    "minecraft:book", 1, "", 0, "", 0, 200, 24
));
```

`registerMachine` 可以添加尺寸不超过 15×15×15 的完整格点定义；每格声明部件角色或留空，必须且只能有一个控制器。用 `new BlueprintItem("my_addon:machine")` 注册自己的蓝图物品，即可配置通用控制器。新加工机器沿用配方引擎与端口；新发电机通过定义的 `generator` 标志使用燃料表，`registerFuel` 追加固体燃料。

API v2 保留 `IndustryRecipe` 注册入口，并将其适配进同一执行引擎；原有单输入配方和附属示例保持可用。新增 `ProcessRecipe` 支持最多六个物品输入、四个物品产物、四路输入与四路输出流体，以及两个保留型催化槽。输入支持 `#namespace:tag`，产物指定精确 ID；槽和通道分别从 0 编号，同类位置不能重复声明。配方仍在构造阶段注册并冻结。参见 [新旧注册示例](examples/ExtraIndustryRecipes.java)。

## 后续开发计划（2026-11-07）

开发和验证目标为 **NeoForge Minecraft 1.21.1 / Java 21**。共振工业包含两条并行主线：内容丰富的**化学工程**，以及采矿、冶金、机械、电气、物流、装配和能源组成的**工业工程**。两线各有起步、中期和后期目标，在具体产品和高级项目上交汇。共振工业继续作为可选附属独立管理版本，主模组剧情可以独立完成。沿用现有 Forge 目录作为共享玩法、资源源和转换入口，公共契约保持 Java 17 兼容，不手改 NeoForge 的生成目录。alpha.2 已开始实现多介质配方基础；下列完整科技树与化学候选清单仍是分阶段设计目标。

### 两条并行主线

| 阶段 | 化学工程主线 | 工业工程主线 |
|---|---|---|
| 起步 | C0 实验室：器具、取样、加热、化学手册；C1 水处理、气体分离与储存 | I0 基础工坊：工具、手动零件、小型动力；I1 采矿、矿石处理、焦化与基础冶金 |
| 初期 | C2 酸碱盐、浸出、沉淀、结晶与工艺回收 | I2 车铣压制、电机、基础电路和 FE 电网 |
| 中期 | C3 石油化工、有机中间体、精馏、溶剂与润滑基础油 | I3 物品运输、分类储存、自动装配和生产监控 |

共同起步只要求原版原料、基础工具和可获得的小型动力。化学设备可接标准 FE，不以完成整条工业任务线作为启动条件；工业基础电路、冶金和机械零件也有基础获取配方。湿法提纯、先进树脂电路和高阶冷却作为跨线工艺提供明确收益。产生副产物的阶段同时提供基础储存或处理办法，高级回收可以后续解锁。手册分为两套进度页，分别展示来源、用途、下一步和可选交汇项目。

交汇项目包括密封与耐蚀机器（C2＋I2）、精密化工工厂（C3＋I3）、先进电路与储能（C4＋I3）、核工业（C4＋I4）及高级核化工服务（C5＋I4）。完整核电站由两线共同支撑；大型热电、制造和自动工厂仍构成可独立完成的工业发展路径。母体、收容和裂隙作为共振生物工业的后期联动。

### 丰富化学的具体范围

第一份[化学设计清单](docs/chemistry-plan.json)收录 **148 项候选物质与工艺介质、12 个化学分支、28 类工艺设备和 12 个生产回路概念**。148 项由 79 项基础物质条目、20 项混合介质、26 项功能材料、12 项废物和 11 项虚构共振物质组成。长期规划为 **350–500 条有用途的独立工艺配方**；配方数量是设计目标，当前清单没有实装这些配方。同一物质的浓度、纯度、相态、包装和来源变化不重复计数。

| 分支 | 候选例子 | 主要用途 |
|---|---|---|
| 水处理与工业气体 | 水、氢、氧、氮、氩、氦、二氧化碳 | 工艺水、保护气、反应介质和冷却系统 |
| 酸碱与基础试剂 | 硫酸、盐酸、磷酸、氢氧化钠、过氧化氢 | 清洗、浸出、反应、电解与中和 |
| 盐类与矿物化学 | 氯化钠、碳酸钠、硫酸盐、磷酸盐 | 试剂、电解原料、水处理与培养添加物 |
| 湿法冶金 | 金属氧化物、硫酸铜、氯化铁、硫酸镍 | 金属提纯、电极原料、分离和回收 |
| 石油与烃类 | 原油、天然气、石脑油、燃料馏分、乙烯、丙烯 | 燃料、润滑基础油、塑料和橡胶原料 |
| 有机中间体与溶剂 | 乙醇、异丙醇、丙酮、乙酸乙酯、甘油 | 清洗、树脂工艺、添加物与溶剂回收 |
| 高分子与功能材料 | 聚乙烯、聚丙烯、聚四氟乙烯、环氧树脂、橡胶 | 绝缘、耐蚀衬里、密封、结构件和涂层 |
| 电子与电化学材料 | 石墨、活性炭、硅、碳化硅、磷酸铁锂 | 电极、吸附剂、电池、先进电路和耐热部件 |
| 发酵、生化与灭菌 | 葡萄糖、酶浓缩物、分离蛋白、壳聚糖 | 培养、净化膜、组织处理和抑制耗材 |
| 环境与资源回收 | 废溶剂、失活催化剂、工艺滤饼、污泥 | 分类处理、介质再生、有限回收与残余物封存 |
| 核工业化学配套 | 离子交换树脂、缓蚀冷却液、屏蔽与封装材料 | 核设施水化学、冷却管理和废物固化 |
| 共振与感染化学 | 共振浸出液、虚空螯合液、孢子抑制剂、导电生物树脂 | 连接感染材料、母体、抑制设备和裂隙工程 |

设备按工艺分类：预处理与分离采用破碎、洗矿、溶解、压滤、离心、干燥、结晶、精馏、膜分离和低温装置；反应采用搅拌、加压、电解、催化、聚合、发酵及灭菌设备；配套采用吸收、解吸、换热、冷凝、中和、尾气洗涤和固化装置。不同规模可以共用工艺能力，设备以实际输入输出和操作方式区分。

化学玩法包含以下决策：

- **工艺选择**：普通冶金与湿法提纯有不同的步骤、能耗、试剂需求和回收收益；石油与发酵原料提供不同的有机化工起步路线。
- **品质与条件**：使用有限的纯度、浓度、温度和压力等级，影响配方可用性、产率及后续用途。相态和品质可有独立运行状态，清单按基础物质归并。
- **催化与再生**：催化剂有占用、失活和再生状态；贵重催化材料可以回收，同时产生明确的残余损耗。
- **材料适配**：管道、储罐和密封件具有耐温、耐蚀、气体适配等属性；材料选择影响能否安全、稳定地运行工艺。
- **副产物流向**：副产物可以供给另一条生产线，废液和尾气分类处理；回收具有成本、限额和最终残余物。
- **规模化**：基础机器采用批次结算，高级工艺再引入分段结算的连续生产、缓冲罐与供需调度；堵塞和断流的状态可读。

每条化学分支都需要“原料来源 → 加工与分离 → 有用途的产品 → 副产物处理”的完整回路。第一批化学内容以 **30–40 项有效物质与介质、60–90 条工艺配方、至少 3 个完整回路**为目标，清单已选择 35 项首批候选，优先水与气体、盐与试剂、组织净化与材料用途。石油和先进材料随后展开，基础化学起步不依赖找到石油。各分支注明主要拓展阶段，葡萄糖、培养基等基础生化原料可提前获得，高级酶催化和共振生化随后展开。

### 实验室起步器皿（alpha.3 已实装）

首批五种玻璃器皿和六工位实验台均有生存配方、独立模型和中英文本；液量以整数 mB 保存，1000 mB 为一桶。器皿不可堆叠，可用铁砧命名。

| 器皿 | 容量 | 可选每剂量（默认加粗） |
|---|---|---|
| 试剂瓶 | 250 mB | 25、50、100、**250** mB |
| 滴瓶 | 100 mB | **1**、5、10、25 mB |
| 滴管 | 25 mB | 1、**5**、10、25 mB |
| 试管 | 50 mB | 1、5、**10**、25、50 mB |
| 烧杯 | 1000 mB | 25、100、**250**、1000 mB |

1. 放置实验台，手持器皿对台面空位右键摆放。台面分为两排三列。水桶、熔岩桶或浆液桶可给烧杯整桶加液；小器皿装不下一桶时，桶与器皿均保持原状。包括创造模式在内，器皿和桶均实际转移，成功装卸后返还对应的空桶或满桶。
2. 手持空器皿右键已有液体的器皿、储液罐或流体端口，取样至容量上限。已有液体时普通右键向目标倒入当前一剂；潜行右键从目标补取一剂。可在副手拿目标器皿，对空普通右键进行同样转移。
3. **潜行对空右键**循环该器皿的剂量。剂量随器皿保存。不同液体、不同流体附加成分、余量不足或目标空位不足时拒绝整次定量转移，不偷偷减少这一剂。
4. **空手右键实验台**打开六工位界面，分别点选“来源”“目标”，切换台子的剂量，再点“定量转移”。实验台可选 1、5、10、25、50、100、250、1000 mB，默认 25 mB。选中的来源器皿也是台子的标准流体接口；台子没有额外隐藏储液罐。
5. **潜行空手右键台面器皿**取回。拆除实验台会掉落所有器皿，内容物、剂量和原物品附加数据保持；存档和区块重载同样保留。满烧杯也可用空桶取回一整桶。

NeoForge 器皿通过可序列化的数据组件保存完整 `FluidStack`，并提供原生物品流体能力，液体的第三方附加成分随样品保留。旧工业罐与管道仍只保存普通单一流体，拒绝带附加成分的液体，防止静默丢弃化学标识。外观以液位档位显示，提示与界面显示精确 mB。加热和搅拌设备使用同一套器皿与流体接口。

锥形瓶、量筒、滴定管和铁架台仍在[设计清单](docs/chemistry-plan.json)中，未计作已实现内容。器皿不计入 148 项物质与介质，也不与 28 类工业工艺设备混计。

### 基础化学实验（alpha.4）

加热台与磁力搅拌台都是可独立摆放的六工位设备。用实验台、铁锭与铜锭制作，额外材料分别是熔炉和红石粉。拿到实验台后可在配方书查看配方。

1. 把烧杯或试管放在 **1 号样品位**，需要液体试剂的实验用 **2 号试液位**。其余四个位用于备料和定量转移。先用水桶装满烧杯，再用空试剂瓶取样 250 mB，可分装出提取所需的水量。
2. 右键打开设备，把固体放入右栏原料槽。加热台放煤或木炭。磁力搅拌台旁接一个打开的拉杆，即可提供红石信号。
3. 点击 **开始** 匹配实验。1 号位需要配方规定的精确液量，2 号位可多放试液，反应会保留多余部分。固体在右栏产物槽取出，液体留在 1 号器皿中。

| 实验 | 设备 | 投入 | 产物 |
|---|---|---|---|
| 烧制碱灰 | 加热台，400°C | 空烧杯或试管，干海带 ×1 | 碱灰 ×1 |
| 果酸提取 | 搅拌台 | 水 250 mB，苹果 ×1 | 果酸浸液 250 mB |
| 碱液浸取 | 搅拌台 | 水 250 mB，碱灰 ×1 | 碱性浸液 250 mB |
| 酸碱中和 | 搅拌台 | 1 号位果酸浸液 25 mB，2 号位碱性浸液至少 25 mB | 中和液 50 mB |
| 蒸发结晶 | 加热台，100°C | 中和液 50 mB | 中和盐晶 ×1，蒸发液量 50 mB |
| 组织清洗 | 搅拌台 | 中和液 50 mB，原始组织样本 ×1 | 纯化组织 ×1，营养浆液 50 mB |

加热台记录温度、燃烧和实验进度。一份煤或木炭提供 240 刻燃烧时间，余热可继续用于加热。搅拌断电时保留进度。产物槽堵塞时等待腾出空间，投入不再满足配方时取消实验。主动停止也会清除进度，未结算的投入可取回。加热台的温度和液量是游戏数值。设备的库存、热状态和进度均会保存。拆下设备会掉落器皿和固体库存。

共振工业手册第 9、10 页列出设备用法及全部六个实验。

### 过滤与蒸馏（alpha.5）

过滤漏斗和冷凝装置均可用实验台和原版材料合成。普通纸可合成两张滤纸。滤纸只在过滤成功时消耗。

| 操作 | 样品与投入 | 产物 |
|---|---|---|
| 搅拌台溶钙 | 1 号位果酸浸液 25 mB，原料方解石 ×1 | 含钙浸液 25 mB |
| 搅拌台沉淀 | 1 号位含钙浸液 25 mB，2 号位碱性浸液至少 25 mB | 碳酸钙悬液 50 mB，保留多余碱液 |
| 漏斗过滤 | 1 号位悬液 50 mB，2 号位放接收器，右栏滤纸 ×1 | 方解石 ×1，2 号位澄清滤液 50 mB |
| 加热台蒸馏 | 1 号位澄清滤液或中和液 50 mB，煤或木炭，连接冷凝装置 | 冷凝装置 1 号位蒸馏水 40 mB，原样品器皿浓缩液 10 mB |

1. 面向加热台，把冷凝装置紧贴右侧放置，两台同向。冷凝装置的 1 号位放有足够空间的试管或烧杯。
2. 装好样品和燃料，打开加热台，点左侧 **蒸馏**。设备到 100°C 后计时。右侧「开始」仍执行烧制或蒸发结晶。
3. 过滤与蒸馏都会检查接收器和产物空间。接收器缺失、容量不足或有不相容液体时暂停。补好器皿后续跑，蒸馏不会自动转成蒸发结晶。
4. 从冷凝装置 1 号位取回器皿，可用原有滴管和试剂瓶转移蒸馏水。蒸馏水可代替水用于果酸和碱液提取。加热前后的总液量仍为 50 mB，浓缩液留在原器皿内。

游戏内手册第 11、12 页有过滤与冷凝的完整操作。

### 当前基础与扩展限制

现有三种多方块、FE 电网、流体运输、取水、储存和机器注册 API 可作为起步层。2026-11-05 的历史记录为每版 12 项原生测试、3 次专用服务器启动和 12 张客户端截图。alpha.2、alpha.3 使用当前 alpha.7 核心单独验证；具体结果记录在本轮验证与预览目录，历史数量不替代本次检查。

- 旧 `IndustryRecipe` 仍保持单输入契约；新增 `ProcessRecipe` 已支持多原料、多介质、保留型催化介质和副产物，随后扩展数据配方、失活再生与工艺条件。
- `IndustryNode` 已扩展为 12 个物品槽和八个罐，并保留旧存档映射；按机器定义配置不同容器规模与运行行为仍需继续实现。
- `MachineDefinition.generator` 只有发电／加工两类，不能直接表达产热反应堆、换热器、锅炉和汽轮机。
- 当前能源接口和传输速率写死，管网只有基础流体路由；高阶工厂需要可配置吞吐、过滤、轮询与明确的额定容量。
- 纯化组织尚无后续消耗配方；每个新材料都要安排实际用途和完整获取链。

### 先建立的公共能力

| 系统 | 设计要求 |
|---|---|
| 材料与介质 | 定义材料 ID、加工形态、标签、液体／气体属性、离散纯度与浓度，以及耐温、腐蚀、可燃、有毒和放射性等游戏属性；普通罐保持单一介质，混合在专用机器内进行 |

| 批次结算 | 完成时一次性扣料并提交全部产物，运行期间持续核对条件；输出堵塞即暂停。定义材料预留和配方版本，重载、多人操作、卸载、拆机不得重复产出或吞掉副产物 |

| 热工 | 独立保存热量、热容量与温度；换热、汽化、冷凝和损耗使用一致的游戏能量账。锅炉、核堆及后期共振热源复用热工能力；冷却水和热介质分别输送 |
| 物流与操作 | 标准物品／流体接口，明确的输入输出面、过滤、红石控制、管材适配与吞吐上限。气体先通过有气体属性的流体定义接入现有接口，第三方专用化学能力另做可选适配 |
| 故障与存档 | 保存温度、压力、燃料、废物和故障状态；停机后仍处理已存热量与压力。依赖区块不完整时整套核设施进入一致的持久化冻结状态，复载不追算离线发电；不能只停冷却泵而让堆继续燃烧 |

### 科技推进与阶段交付

```text
共同起步：原版原料、基础工具、小型动力
  ├─ 化学工程：水与气体 → 无机化学 → 有机与石油 → 高分子、精细材料 → 生化与共振化学
  └─ 工业工程：采矿冶金 → 机械加工、电气 → 物流装配 → 大型热工 → 综合工业基地

交汇升级：耐蚀密封、润滑、精密设备、先进电子与储能
交汇项目：核燃料组件 → 受控裂变 → 换热、蒸汽、汽轮机、冷凝 → 废物处理
后期联动：共振材料、母体监测与受控裂隙工程
```

| 顺序 | 建议目标 | 化学线交付 | 工业线交付 | 完成标志 |
|---|---|---|---|---|
| 1：共同基础 | 0.1.0-alpha.2 | 可扩展配方、介质、容器和催化条件；实验室手册框架 | 核心兼容、旧三机迁移、物品管、过滤和红石控制 | 旧库存与配方保留；箱子供料、自动加工、出料，满箱与重载可恢复 |
| 2：双线起步 | 0.2 系列 | 水与气体、盐与试剂、生化净化用途，分批达到首批化学内容目标 | 采矿冶金、金属成形、电机与基础电气 | 两套进度页各有完整可玩的生产回路，基础获取不要求另一条主线通关 |
| 3：双线扩展 | 0.3 系列 | 石油、有机溶剂、润滑、高分子和循环处理 | 分类物流、自动装配、储能、锅炉与蒸汽回路 | 化学产物供给工业升级，机械与热工提升化工规模，交汇收益可衡量 |
| 4：精密与核工业 | 0.4 系列 | 精细与电化学材料、催化再生、先进水化学及废物处理 | 精密制造、大型热工和首种受控裂变多方块 | 核电站有完整冷却、急停、辐射监测、屏蔽和废物去向；常规大型工厂同样可继续发展 |
| 5：后期发展 | 0.5 系列 | 深度生化、共振材料和先进介质 | 综合工业基地、大型工程及共振能源设备 | 两条线各有后期成品，并可协作完成母体监测、高阶抑制设备和受控裂隙工程 |

核工业先完成一种可控的发电反应堆和完整配套，再讨论更多堆型。第一套核设施的材料由前面的冶金、化工和热工取得，避免必须先有核堆产物才能造第一台核堆。乏燃料再处理有有限回收率和残余废物，防止回收循环凭空增殖游戏资源。

现有燃料发电机 64 FE/t、处理罐 16 FE/t、离心机 24 FE/t 和持续抽水约 5 FE/t 保留为起步平衡基线。升级按整线净耗电、材料来源和副产物去向计算，纳入燃料残渣回烧、换热损耗和冷却辅助用电。核堆优先作为热源，由汽轮机输出 FE；所有新增材料在同一阶段给出用途。

### 近期实施与验收

下一轮先完成两线共用的基础，具体顺序为：

1. 用当前核心开发包重新运行 NeoForge 附属的原有测试、真实重启／区块卸载验收与客户端生产线检查。保留历史证据与本次证据的区分。
2. 定下材料、配方、槽罐、端口和机器行为的数据结构，用旧三机完成兼容迁移；以一个“双流体＋物品催化剂”的游戏配方检查新引擎。
3. 打通箱子供料、物品管、过滤、红石停机和自动出料；新增多输入结算、催化剂、配方重载、分支供给与吞吐上限的原生测试。
4. 给手册和配方展示补齐原料、过程、副产物与用途，交付可玩的共同基础版本，再并行推进化学与机械内容。

随后以普通燃料锅炉验证热工。化工和核能的实际配方、设备尺寸及数值在各阶段另做设计和验收；不把本计划里的名字当成已注册内容。

工业附楼、化工车间、管线廊与后期核设施随对应生产链分批设计，按方块坐标和图纸交付。空间预留操作面、装卸、管道和维护路线。生成的研究所附属区域纳入剧情保护边界，剧情必拆目标单独登记；玩家自建工厂采用普通建筑规则。

研究所供电状态、工业 FE、热量和 F7 锚点能量分别保存，按明确规则转换。F7 母体不作为无成本的发电开关；母体绑定、破舱和死亡状态通过明确接口衔接，不复制实体或重置资源。核设施的废物、污染和损伤也不能靠拆掉控制器后重建清空。

每阶段保留原有测试，并补充真实服务器重启、区块卸载、多人菜单与客户端实景。重点核对物料和能量账、温压边界、输出堵塞、异常停机、拆装迁移和长时间运行。当前可玩实例及已有世界不用于自动化测试。主模组与附属继续使用各自的版本、验证记录和发行附件。
