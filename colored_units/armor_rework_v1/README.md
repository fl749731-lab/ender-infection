# 轻甲与金缮重甲改造

重甲采用 [Kintsugi Armor — @eanncrod](https://blockbenchworkshop.com/model/eanncrod/kintsugi-armor)，许可为 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。作品页允许修改和随项目再分发，要求署名、链接许可及标明改动。该旧条目未记录作者权利声明，AI 使用情况未披露；不能写成已独立核实原创。公开预览 JSON、来源 URL、SHA-256 和改动清单见 `source` 与 `provenance.json`。

保留作者深色金属与金缮裂纹的原始 128×128 像素。调整头盔宽度、胸甲上沿和臂甲长度，移除七个铆钉状突起，加入本项目紫晶。右腿和右靴原有转轴错误已修正；左右侧裙和分开的两片前裙跟随各自的大腿。一个超出贴图左边缘的面 UV 移回有效区域。最终 40 方块、8 骨骼。

轻甲继续改造项目自有的晶壳轻甲底模，保留层叠肩甲、护臂、拳甲、胫甲与胸口晶核。去掉重复晶核、遮挡脸部的鼻梁和过大的头顶装饰，清理延伸到头盔的肩带，缩窄肩甲并修正手臂偏移。头盔露出穿戴者脸部，与重甲封闭面甲保持区别。最终 101 方块、8 骨骼。

模型、几何编辑、UV 修正和 GeckoLib 几何导出均通过 Blockbench MCP 完成。两个模型使用八个标准装备骨骼，没有额外的未受装备槽控制的腰部根节点。穿戴动作直接跟随 Minecraft 的 `HumanoidModel`，没有播放独立人物动画，因此 MCP 动画检查显示“无动画，跳过”，不能当成行走或蹲下已验收。

材质无损打包为 256×128 图集。只有紫晶面选择的完整不透明像素进入发光蒙版；没有让金属、金色裂纹或皮革整体发光，也没有动态环境光源。紫晶采用低频色阶，尺寸较小的晶尖与大晶体共享材质；原作者装甲面的纹理密度保持原样。物品栏四件模型按真实装备部位重新烘焙，保留立体旋转、表面膨胀和贴图。

静态检查保留完整报告：重甲 48 个警告主要是甲片交叠的包围盒和左右命名，轻甲 8 个警告包括穿戴者支撑的独立部件及甲片交叠。无负尺寸或损坏层级。实际穿戴、单槽可见性、混穿、走动、蹲下、拉弓、骑乘和暗室发光以双版客户端记录为准，详见[双版验收记录](../../previews/armor-rework-v1/README.md)。

`models` 为编辑源，`mcp_exports` 为 MCP 原始输出，`export-lock.json` 锁定其哈希。`tools/export_armor_reworks.py` 负责材质打包、装备槽契约和物品网格转换，并在全量旧导出之后覆盖这两套资源。注册 ID、配方、护甲数值和套装效果保持现有实现。两版客户端使用各自依赖的 GeckoLib API；Neo 资源由 Forge 自动同步。

本轮改造为 AI 辅助制作，属于 alpha.8 开发分支；未创建新的公开发行。
