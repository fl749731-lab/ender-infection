初期形态沿用现有注册 ID、属性和碰撞体，包含五动作。牛 14／30、猪 12／28、羊 20／40、蜘蛛 12／26 tick 的命中／总长分别保留；四种死亡均在 18 tick 内完成。它们和完全畸变体共用物种关节语言，但局部病灶、皮毛完整度、体型与攻击幅度有区别，并非只缩小同一个大晶簇。初期蜘蛛保留公开原作的身体图像，署名与改动单列在 `early-provenance.json`。骨骼和时点通过 MCP 48 Hz 检查，无动画错误／警告。

用户提出贴图偏平后，六只牛／猪／羊采用新的 `materials/quadruped-atlas-v2.png`：牛皮斑块有更自然的边缘和毛色变化，猪皮有细微色差、褶皱与斑点，羊毛按毛团区分明暗，骨质、裂口和蹄壳分别细化。使用内置 imagegen 编辑材质母版，保持原 UV 布局和像素风；缩回逻辑 128×128 图册时只替换六个材质区，眼睛、鼻孔和其他特殊像素原样保留。晶体使用独立原有素材和精确蒙版；体表不会因使用紫色裂口就整片发光。工具、完整提示词、母版和哈希见 `materials/generation-v2.json`；`tools/pack_quadruped_materials.ps1` 可重复执行尺寸转换与图块保留。没有改用 CLI/API 回退路径。

喷吐者的可编辑源仍在 `design_pack_2026-11-02_v2/monsters/rift_throat_spitter.bbmodel`：两个完整曲面囊体等比收缩到原来的 65%，移到喉部两侧并接回胸腔，增加两个连续接管，保留充盈／压缩节奏和 24／52 tick 吐射时点。两个亚像素悬空尖端合并进前一段，总计 443 方块、14 骨骼；死亡改为 18 tick 并避免重复的整身翻转。几何仍有细小晶面、骨甲嵌入与旧命名造成的检查警告，未宣称无警告；没有悬空部件，动画 48 Hz 检查 0 错误／0 警告，同向共面重叠检查为 0。原源文件、变更、检查与哈希见 `spitter-rework.json`。

三种四足动物的旧原始模型留在 `source/project-original`，来源哈希、材质／几何预算和公开候选的取舍见 `quadruped-provenance.json`。未导入高地牛、Grimwool 羊和 Celestial Caprine Zombie：这些候选只允许展示；免费猪候选是苦力怕／蜜蜂融合，未作为普通畸变猪底模。三只采用项目自行制作的物种材质图块，紫晶沿用原有牛模型的晶体像素。原创改造记录独立放在运行署名文件的 `original_reworks`，不标成第三方 CC BY 作品。

三只均有待机、四足行走、攻击、感染、死亡。牛命中／总长为 14／30 tick，猪 12／28，羊 20／40；死亡均为 18 tick，保留原 ID、属性和碰撞体。四条腿拆出膝关节，耳、尾和下颌独立转动，循环动作闭合。按 48 Hz 和关键时点修正接地，再经 MCP 48 Hz 检查：三只动作均 0 错误、0 警告。静态几何分别有 26／25／44 个跨组包围盒嵌入警告，主要来自关节、羊毛、裂口和嵌入晶体；没有缺失、悬空或退化部件，同向共面重叠检查为 0。未把这些连接处的包围盒警告冒充全部消除。

[牛、猪、羊的双版运行实景与验收](../../previews/quadruped-rework-v2/README.md)。下文为蜘蛛的单独来源和适配记录。

原模型：[Spider — @elma_taburlas](https://blockbenchworkshop.com/model/elma_taburlas/spider)，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。作品页声明 Human-created；本次适配为 AI 辅助。完整公开 viewer JSON 留在 `source`，来源地址、原始 SHA256 和修改项见 `source-provenance.json`。原作者的作品未改为本项目原创。

保留原作的条纹、八只分节足、足尖、红眼和口器；腹部向后展开，晶体长在腹部和头侧，避免堆成直立方柱。新增六处晶体生长点，共 69 个方块、61 个骨骼。原始身体贴图像素直接保留，新增晶体沿用本模组原有素材，合并为 256×128 图册；只让实际使用的晶体 UV 发光，身体和红眼不加入发光蒙版。

| 动作 | 运行契约 |
|---|---|
| 待机 | 合并原作的呼吸、眨眼和口器细动；首尾闭合 |
| 行走 | 八足分节交替，0.8 秒循环；首尾闭合 |
| 攻击 | 1.5 秒，0.7 秒对应现有第 14 tick 命中；不改变战斗数值 |
| 感染 | 1.6 秒，与现有出场控制器对应 |
| 死亡 | 0.9 秒收足倒伏，在原版 20 tick 移除前结束；关闭重复的原版整身翻转 |

可编辑项目通过 Blockbench headless MCP 创建、调整、检查并导出。`mcp_exports` 为 MCP 原始几何／动画导出；`export-lock.json` 锁定项目与两份导出的 SHA256。`mcp-verification.json` 保留检查结果。导出器按材质合图、平移 UV、归一尺寸并绑定运行 ID；不从脚本重新生成本体几何。

240 FPS 的编辑吸附精度用于保留 24／48 Hz 采样和 20 Hz 的命中时点。动画以 48 Hz 检查，0 错误、0 警告；几何检查有 113 个深层包围盒重叠警告，原作基线为 91 个，主要是分节连接、眼部和新增晶体的嵌入。几何 0 错误；独立同向共面面检查没有重复覆盖。这些包围盒警告并未宣称全部消除。

`infected_spider` 注册 ID、2×1.6 游戏碰撞体、攻击范围和伤害保持原样；展开足部的视觉宽度约 3.02 格，属于原种蜘蛛的外伸足。初期感染蜘蛛另外适配，展开宽度约 1.41 格，不改变原有 1.4×0.9 碰撞体。
