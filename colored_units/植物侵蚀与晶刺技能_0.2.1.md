# 末影感染 0.2.1：植物侵蚀、地表节点与畸变技能

Minecraft 1.20.1 · Forge 47.3.12 · Java 17 · GeckoLib 4.4.9。

## 植物跟随地面逐步侵蚀

节点附近的草、蕨、花、小蘑菇、下界菌类、树苗、浆果灌木和常见农作物现在可被侵蚀。初期保留原版形状、透明边缘和原色，只增加少量紫色侵蚀；地面继续感染后，植物侵蚀加深，再转成阵营的感染草、裂口花或末影菌。两次初期外观属于同一个“侵蚀阶段”，随后进入完全感染阶段。

覆盖 31 种单格基础植物、5 类作物或浆果的生长状态（合计 63 个单格外观配置），以及高草、大蕨、向日葵、丁香、玫瑰丛、牡丹、瓶子草等 7 种双格植被。草和蕨沿用所在生物群系的草色，紫色覆盖层不参与绿色染色。农作物保留被侵蚀时的生长外观，侵蚀作物本身不继续进行原版生长。树苗保留树种外观；树干和树叶沿用已有的树种侵蚀系统。

菌丝体原本已列入地面侵蚀范围。本次让其上方的小蘑菇参与转换，避免花草和蘑菇挡住地表扩散。湿润和干燥耕地保留原版贴图及 15/16 格高度。双格植物上下两格一起转换，完全感染后移除不再使用的上半格。

土壤和植物按实际改变的格数消耗所属母体的生物质。例如普通地面加一株植物共消耗 2；地面加双格植物共消耗 3。资金不足时整组保持原样。植物没有独立扩散计时器，只有扩张节点能够推动这些变化，仍遵循 `mobGriefing`。

每轮按实际变化格数限制处理量，双格植物可整体使用本轮名额；通常为树干、树冠修复保留一格处理名额，避免新地面扩张挤占全部维护机会。地面单位刚生成尚未落地时暂缓远距离路径判定，避免过早把可达猎物加入失败冷却；出场期间仍能记录亲眼看见的目标，隐藏目标不会凭空提供实时坐标。

这是上述植物的支持范围；大型蘑菇的菌盖和菌柄、藤蔓、竹子、仙人掌等不在本轮新增列表中。

## 自动节点替换地面

母体建立初始节点和成熟节点建立子节点时，现在直接把所选地表方块替换为 `infected_nest[rooted=true]`，保留所属母体及原方块 ID 记录。初始节点允许选择可感染的天然地面，子节点选择已感染的边缘地面。节点仍只有一种类型，可存在多个；资源、距离、容量、养分选址与失败退款规则继续生效。

新节点的基座占据地表格，晶簇露出地面。旧存档已放置的普通节点及创造栏的常规方块放置方式保持原位置；旧节点不会自动搬动或挖除周围地形。

## 完全畸变单位的特殊攻击

| 单位 | 新增技能 |
|---|---|
| 牛感染体 | 朝前连续刺出的直线晶刺 |
| 猪感染体 | 近前方分叉的晶刺冲击 |
| 羊感染体 | 围绕自身的环形晶刺，附加减速 |
| 蜘蛛感染体 | 目标脚下与四周的晶刺围笼，附加较强减速 |
| 末影人感染体 | 目标周围的十字裂刺，附加减速 |
| 骷髅感染体 | 用魔法阵和七点晶刺替代弓箭；双臂水晶施法模型与动作 |
| 畸变僵尸 | 砸地攻击带出朝前的晶刺列；其他爪击、脉冲继续保留 |

初期侵蚀单位保留基础攻击，初期骷髅仍使用弓箭。母体和晶冠攻城兽继续使用已有的阶段技能与晶体波。

地刺是短时间存在的技能实体，不会把地面永久替换成晶体方块。先显示魔法阵预警，再从地面刺出并结算伤害；目标可以在预警期间躲开。一次施法对同一敌人最多结算一次晶刺伤害，排除感染阵营友军。近战打击仍可独立生效。技能检查地面、液体和遮挡；施法者死亡或攻击被回防命令打断后取消未完成的晶刺。技能不会在保存重载后重新播放伤害，并限制同时存在的数量。

## 快速测试

先使用 `/enderbiomass` 查看附近母体是否有可供扩张的储备，`/enderstrategy` 查看单位任务。正常变化需要活跃且有资金的所属母体、扩张节点及已加载区块。

创造测试可用：

```mcfunction
/summon ender_infection:infected_core ~5 ~ ~ {MotherStage:1,ColonyBiomass:300,EmergenceTicks:0}
/summon ender_infection:infected_skeleton ~5 ~ ~ {EmergenceTicks:0}
/setblock ~3 ~-1 ~ ender_infection:infected_nest[rooted=true]
```

手动放置的测试节点会寻找附近可用母体取得归属；单独创建无主节点不会免费扩散。可在附近放置菌丝体与小蘑菇、湿耕地与不同年龄的作物、大蕨或双格花，观察初期保色、加深和最终感染。

安装状态见工作区 `outputs/安装状态.txt`；完整测试结果见 `verification/RESULTS.txt`。`outputs/eroded_vegetation_preview.png` 是贴图对照，`outputs/crystal_caster_preview.png` 是离线模型预览，两者均不是游戏截图。自动测试使用隔离测试世界，没有打开玩家存档；客户端观感和长期平衡仍需实机确认。五阶段母体、生态收益、Boss、掉落与合成继续参考《生态与高阶母体_0.2.0.md》。
