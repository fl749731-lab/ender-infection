# 研究所柜门、显示器与双开门

适用于 0.12.0-alpha.7。保留现有方块 ID、库存和存档；模型修复也适用于旧研究所中已有的对应家具。

## 双开门

将两扇**同类、同朝向、门禁标记相同**的研究所门并排放置，即组成一套双开门。普通门与侵蚀门分别配对；三扇连排不自动拼接，防止中间一扇同时属于两组。

左右门扇绕外侧铰链向外打开，中间门柱移除。右键任一门扇或其上半部，会同步打开或关闭两扇。单扇门继续独立使用。配对按相邻方块判断，无需拆掉旧门重放；旋转建筑后仍按朝向正确配对。

北向示意，单位为模型像素（16 像素＝1 格）：

```text
外侧门柱      左门扇      中缝      右门扇      外侧门柱
x=-8           ────────→ x=8 ←────────          x=24
         铰链在外侧                     铰链在外侧
```

开门时中间保留连续通路。破坏其中一扇只移除它自己的上半部，另一扇恢复单门使用。门禁同时检查两扇：即使点的是临时加装的一扇，也不能绕过设施侧门的供电和门禁卡限制；室内应急开门继续有效。

## 柜门与显示器

实验室储柜、玻璃样本柜、低温封存柜与服务器机柜按实际铰链方向向柜外开门，避免门板穿过层板或内部设备。真实箱子菜单、27 格库存、多人开柜状态及战利品规则保持原样。

接待台原先把壁挂显示器放在柜台上，底部没有连接支撑。显示器补充落台底座与连续支杆，背面的壁挂连接结构保留；已经摆放的显示器直接使用新模型。

## 验收与维护

两版原生测试覆盖四个朝向、普通／侵蚀材质、双门上半部交互、中心通行、拆除单侧、三门排除及门禁防绕过。真实客户端另记录柜内、门扇、隔帘和接待台前后视图，见[本轮实景记录](../previews/lab-fixture-alpha7/README.md)。

建筑继续用方块坐标和原生结构维护。双门运行几何由 `tools/export_lab_door_variants.py` 从单门生成；显示器源在 `colored_units/lab_details_v3/lab_monitor.bbmodel`，由 `tools/build_lab_details.py --only lab_monitor` 更新，避免覆盖其他已升级家具。发布前检查双门导出未过期，并执行完整双版本发布门槛。
