# 主线流程

适用于主模组 0.12.0-alpha.6，Forge 1.20.1 与 NeoForge 1.21.1 同步提供。

| 步骤 | 位置与操作 | 完成后获得 |
|---|---|---|
| 1. 寻找研究所 | 探索新区块中的中央研究所，收集公共补给，拿到研究日志 | 保险丝、样本与起步物资 |
| 2. 修复电源 | B1 / D2 发电机：保险丝 ×1、铜锭 ×4、红石 ×4 | 可以操作配电控制器 |
| 3. 分区送电 | B1 / D1 控制器：主手普通右键切换服务区；主手空手潜行右键切换收容区 | 照明、设备与门禁供电 |
| 4. 领取门禁卡 | 服务区供电后，G1 / A7 研究终端右键 | 每名玩家各一张门禁卡 |
| 5. 分析与分离 | 在供电区的显微镜和离心机完成本设施研究 | 研究记录与分离试剂 |
| 6. 读取核心档案 | 保持收容区供电，B3 / F5 提交研究记录 ×1、分离试剂 ×1 | 核心档案 ×1、虚空晶 ×2；每所共用一次 |
| 7. 处理 E8 事故 | 完成分析与分离后，持门禁卡操作 B2 / E8 终端；清理两波敌人并维修设备 | 研究记录 ×1、虚空晶体 ×1；每所共用一次 |

E8 的研究前置不要求先领取 F5 奖励；上表把档案放在前面，便于按楼层完成探索。E8 维修需要铜锭 ×2、红石粉 ×1，最后主手空手潜行右键隔离阀。操作点与等待条件见[研究所操作](institute-operations.md)和[E8 指南](containment-incident.md)。

当前主线到 E8 事件。研究所 Boss 及其奖励尚未接入。共振工业为可选的独立生产线，不以研究所现有供电代替 FE 发电。

## 已有世界

E8 需要 v4 结构中的专用终端与故障设备。旧研究所不会自动改写，已有战利品不会重抽。请在新区块寻找新版建筑，或由管理员在合适空地[预览和施工](central-institute.md#管理员检查与放置)。
