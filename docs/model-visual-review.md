# 怪物、装备与特效评审

2026-11-06，针对 alpha.7 开发资源。用户选择“外观和动作优先，保留有用的立体细节”。本轮检查 **36 个怪物外观、11 种武器（含三系斧）、5 套护甲与 7 类粒子效果**，包含全部初期感染及畸变生物，并附九种采集工具的素材记录。

先修畸变牛、猪、羊、蜘蛛的盒状体块与暗色材质，再加强畸变僵尸动作。初期感染保留物种特征，不统一换成人形骷髅或龙。其余明确有辨识度的虫体、翼膜、盾牌和巢体保留，在现有结构上调整。

## 检查方式与证据

从当前游戏 `.geo.json`、贴图与动画生成 MCP 检查工程，每个形态采集正面、侧面、背面、行走和攻击姿势，共 **180 张检查图**。它们用于轮廓、骨骼与材质评审，不能证明完整动作周期、碰撞或 AI 都正确。初期感染与畸变各有独立对照；母体按五阶段计数，监管体单列。

暗室补查发现：畸变羊、畸变蜘蛛、初期骷髅和初期僵尸的晶体有单侧遮挡，不能靠增加发光强度解决；需要在模型改造时调整生长位置与可见轮廓。发光验收按每只生物的前／后成对视图判断，排除远处其他怪物的亮点。

这些对照图记录本轮替换前的基线。两只新模型另作待机、移动、攻击、死亡及循环采样，并通过两版真实客户端检查；运行证据集中在[本轮验收](../previews/public-model-adaptations-v1/README.md)。MCP 动作检查以 24 Hz 采样，修改后待机、行走及攻击的动画骨骼、时序、接地与脱节门槛均通过。死亡动作的倒伏允许接触地面。

## 第二批开发进展

alpha.8 开发分支已将畸变蜘蛛替换为 @elma_taburlas 的 CC BY 4.0 分节蜘蛛底模：保留原始条纹、红眼和口器，新增头侧／腹部晶体，重做攻击、感染和死亡，合并并校正待机与八足步态。不是仅换贴图。两版原生 AI 各 36 项通过，另有 22 张真实客户端最终截图；[模型来源与修改](../colored_units/creature_rework_v2/README.md)、[运行验收](../previews/creature-rework-v2/README.md)。公开发行仍为 alpha.7。

初期蜘蛛、畸变牛／猪／羊及下表其余项目仍按逐种改造推进。本轮没有把所有怪物或装备标记为已替换。

## 畸变：下一批优先项

| 对象 | 本体问题 | 动作／材质方向 | 优先级 |
|---|---|---|---|
| 畸变牛 | 高肩、后躯、头颅和侧面肿块形成多个硬盒 | 收紧肩背连接；保留牛脸与残余毛色；头部蓄力后再冲撞 | 高 |
| 畸变猪 | 大嘴与下垂颌占比过大，身体像上下堆叠 | 保留猪鼻；重做颈部与咬合连接；加入前扑／咬合收势 | 高 |
| 畸变羊 | 几乎没有羊毛特征，方形侧肿块过重 | 恢复零散毛团、蹄与羊脸；晶体从脊背和弯角生长 | 高 |
| 畸变蜘蛛 | alpha.8 开发版已换为后伸腹部、分节八足与口器 | 已完成步态、攻击和死亡接入；继续关注外伸足与地形的贴合 | 已接入／待后续地形复核 |
| 畸变骷髅 | 肋骨与肩晶有立体结构，但远景易与祭司混同 | 保留瘦骨架；明确晶弓／射击职责，减少悬浮配件 | 中 |
| 畸变末影人 | 骨架、胸核与手指细节成立；轮廓较整齐 | 保留；攻击拉伸与传送残影，适量不对称晶壳 | 中 |
| 畸变僵尸 | 肩甲、手爪有细节，但站姿过直，像穿甲人 | 一侧臂膀增重；拖步、扫爪与重砸区分；保留破衣和僵尸头 | 高 |

此表是实际检查结论，四足畸变体的重塑尚未冒充完成。更合适的起点是现有早期感染原种与已完成的四足关节结构，按每个物种重建，而非把同一公开龙模型套给所有动物。

## 执行顺序

1. 完成当前两只公开底模适配及双版游戏验收。
2. 重塑畸变牛、猪、羊、蜘蛛，保留各自原种特征；同步修初期感染的重复晶簇。
3. 畸变僵尸动作、喷吐者囊体连接、伏击者起跳／落地。
4. 重甲与轻甲轮廓分化、法杖和弩的使用状态。
5. 普通攻城环升级为立体浪，碎片和命中效果配合武器动作。
6. 母体 1—4 阶形状分化；其余怪物按表在原结构上细修。
