# 成熟地表生态与阶段三后的无界扩张

> 一句话定位：彻底侵蚀的土地开始自己「活着」——长植物、孵畸变兽；而三阶之后，扩张不再有节点数与距离上限。

---

## 一、三阶后取消扩张上限

| 项目 | 一、二阶 | 三阶起 |
| --- | --- | --- |
| 自动节点上限 | 6 | 无上限（内存硬顶 256） |
| 铺设距离 | 母体 48 格内 | 无上限（超过 1024 格视为不可达） |
| 单节点半径 | 16 格 | 16 格（性能上限，未改） |
| 单位巡逻/回防半径 | 48 格 | 48 / 64 / 80 格（按阶段，未改） |

放开的是节点网络，不是单位的腿：expansionReach() 决定节点能铺多远、领土算多远；expansionRange() 仍决定猎手、援军、攻城兽的活动半径，两者已经拆开。限制扩张的只剩钱包与已加载区块。

## 二、成熟地表自己产出畸变兽

ExpansionNodeEntity 新增一条独立通路：spawnFromGround() 每 SPAWN_BASE_TICKS（基础 600 tick = 30 秒，随财富最高 4 倍速）在节点半径内找一列彻底侵蚀的地表，交给母体的 spawnFromSoil() 生成一个单位。

| 规则 | 说明 |
| --- | --- |
| 什么算彻底侵蚀 | living_tissue / crystal_crust / mycelial_mat / necrotic_soil / tainted_grass，或 eroded_* 且 EROSION 已到 2 |
| 位置 | 该列地面之上，且上下两格都是空气、无液体 |
| 谁付钱 | 所属母体，早期单位 8 / 进阶单位 24；付不起就不生成 |
| 数量上限 | 与普通孵化同一个 MotherBrain.cap(stage)（4/8/14/20/28） |
| 兵种 | 与孵化同一套 pickHost() 与战术记分，三阶起有概率直接出进阶体 |
| 记账 | 走 spendForHatching，会计入经济策略的孵化支出 |

也就是说：母体只是其中一个产卵点，成熟的地表本身也是产卵点，但两者共享同一份钱包和同一份人口上限，不会凭空刷兵。

## 三、成熟地表自然长植物

growFlora() 每 FLORA_BASE_TICKS（基础 100 tick = 5 秒）在节点半径内挑一列彻底侵蚀的地表，按权重长出战：

| 植物 | 权重 |
| --- | --- |
| 裂口花 infected_flower | 2 |
| 末影菌 infected_fungus | 1 |
| 感染草 infected_grass | 1 |
| 地面触须 infected_tendrils | 1 |

密度用已有的 hasPlantRoom 限制（7×7×3 范围内最多 2 株），所以不会长成一片糊。植物本身不消耗生物质——它们算地表自己长出来的，也不产生土地收入。

目前没有独立的「末影花」方块，用的是现有四种感染植物；要做成新方块需要新贴图与新模型，可以下一步加。
