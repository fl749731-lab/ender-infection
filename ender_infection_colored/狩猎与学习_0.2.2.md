# 狩猎嗅觉与母体自学习

> 一句话定位：把「只有看见才追」改成「闻到就去确认」，并让每只母体按自己的战果调整狩猎积极性与经济分配。

---

## 一、狩猎行为改动

单位原先只有在视野内（跟随范围 40 格）看见猎物才会分配目标，一旦猎物在森林、墙后或地形起伏中脱离视线就不再主动寻找，表现为「待在母体旁边不出去狩猎」。

| 行为 | 旧 | 新 |
| --- | --- | --- |
| 目标发现 | 仅视线内 40 格 | 视线内 40 格，另加 20–48 格嗅觉范围 |
| 嗅觉目标要求 | —— | 必须路径可达（createPath 可达）才出发 |
| 目标丢失后黑名单 | 10 秒 | 6 秒 |
| 候选猎物不可达黑名单 | 4 秒 | 3 秒 |
| 空闲巡逻半径 | 20 格 | max(20, 嗅觉半径) |
| 敌对/玩家围攻上限 | 3 | 3–4（随攻击性） |
| 普通动物围攻上限 | 1 | 1（保持不变，仍分队分食） |

嗅觉不会穿墙锁敌：只设置一个带 ±3 格抖动的搜索点，不把实体位置交给追击逻辑，所以墙后隐藏的移动目标仍然只按最后目击点搜索。

## 二、自学习的三层结构

三层都按母体独立保存，互不共享；分别写在 `BroodLearning`（一、二层）与 `ColonyPolicy`（三层）。

### 第一层：兵种偏好（原有）

「战术 × 兵种」记分表（-18..18）。造成伤害 +1、击杀 +3、本单位阵亡 -4，随时间衰减；孵化时按记分选择兵种（`MotherBrain.pickHost`）。

### 第二层：攻击性

0..100 的 aggression，用指数平滑跟随战果：伤害信号 60、击杀 80、阵亡 10，`aggression += (signal - aggression) / 8`；约 60 秒无战果向中性值 50 回落。派生狩猎嗅觉半径 20–48 格与敌对围攻上限 1–4。

### 第三层：四臂经济策略

孵化与扩张原本是写死的优先级。现在由 `ColonyPolicy` 在四条手臂间学习：

| 手臂 | 含义 | 生效时母体做什么 |
| --- | --- | --- |
| `HATCH` | 现在就把生物质换成单位 | 照常尝试孵化 |
| `EXPAND` | 把钱留给节点网络 | 本决策不孵化，状态显示「优先扩张领地」 |
| `EVOLVE` | 为下一阶段攒钱 | 本决策不孵化，直到凑够进阶价 |
| `RECOVER` | 留出治疗储备 | 残血时优先恢复、不孵化 |

| 项目 | 规则 |
| --- | --- |
| 采样窗口 | 600 tick（30 秒） |
| 适应度 | 领土权重 × 0.06 + 击杀 × 4 − 阵亡 × 6 + 累计收入 × 0.5 |
| 信用分配 | 窗口结束时按当前手臂记账，EMA 系数 0.65 |
| 探索 | ε = 0.2 随机换臂；未采样手臂给 1.1/√n 乐观加成，保证四臂都会被试到 |
| 生效门槛 | 满 6 个窗口（180 秒）才开始真的「不孵化」 |
| 兜底 | 生物质 ≤ 24、没有已拥有节点、母体正被敌人攻击时一律不保留 |

### 节点级账本

`ExpansionNodeEntity` 记录自己花了多少生物质（`spentBiomass`）、换到多少格地表（`purchasedChanges`），对外提供 `territoryPerBiomass()`。母体把名下所有节点的账本汇总成 `nodePurchasedChanges / nodeSpentBiomass / nodeEfficiency`。

`EXPAND` 手臂的得分不是只看全局适应度，而是额外加上窗口内**节点真实产出**：`0.35 × 新增格数 / 新增花费`。也就是说，一个只烧钱不铺地的节点无法长期把母体留在扩张模式，反之高效节点会让母体更愿意把生物质留给它。账本每个窗口读一次，不逐 tick 遍历。

## 三、查看方式

    /enderstrategy

输出三行：母体教导（攻击性 / 围攻上限 / 嗅觉半径）、经济策略（当前倾向 / 已观察窗口 / 孵化与扩张收益 / 节点效率）、附近单位当前任务。
