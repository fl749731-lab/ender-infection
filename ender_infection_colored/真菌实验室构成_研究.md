## 4. 关键设计手法（值得借鉴的五点）

1. **多房间复合体，不是单间**：走廊 + 隔墙 + 加固门，房间成网格，玩家需要逐间搜索。
2. **强识别度的配色**：白瓷砖 + 黑白棋盘地 + 金属通风口，一眼就是"研究设施"，而不是"石头盒子"。
3. **功能叙事**：铁栏杆围出 2×2 的监禁区、6 个刷怪笼、手术台/孵化器类家具 —— 建筑本身在讲故事（这里关过、养过实验体）。
4. **大面积开窗 + 破损**：整面墙的玻璃板窗，配合缺块、积水、菌丝蔓延，形成"废弃后被占据"的层次。
5. **屋顶轮廓**：玻璃中庭 + 铁栏笼 + 菌塔，远距离就能认出地标，而不是平顶黑盒。

## 6. 若要复刻，建议的落地步骤

1. 先做**材质族**：`lab_tile_white` / `lab_tile_checker` / `lab_tile_brick` / `vent_plate` / `reinforced_door`（5 个方块）。
2. 再做**小结构模板**：单层"标准实验室单元"（走廊 + 两间对立房间 + 窗带 + 通风口），先在代码里生成 1 个单元验证观感。
3. 用**单元拼接**替代手工整栋：4×4 网格摆放单元，随机挑 2–3 间做成监禁区/储藏间/手术间。
4. 楼层重复 2–3 层，顶部加玻璃中庭 + 菌塔，形成地标轮廓。
5. 最后补功能：刷怪笼换成我们的节点、箱子换成实验室战利品表。

## 7. 补充研究：所谓"每个群系风格不同"，其实是 5 座不同的建筑

Spore 只有 **一座** 实验室：`spore:lab`，且 **只生成在蘑菇岛（mushroom_fields）**。
`lab/start_pool.json` 里只有一个元素、权重 1，没有任何变体。

真正造成"每个群系不一样"的是这个标签：

```json
// data/spore/tags/worldgen/structure/laboratories.json
{ "values": ["spore:lab", "spore:mines", "spore:hospital", "spore:military_camp", "spore:prison"] }
```

即 **5 座不同的建筑被打包成"实验室"这一类**，每座绑定一个群系：

| 结构 | 群系 | 体量 | 主材（按数量） |
|---|---|---|---|
| `spore:lab` | 蘑菇岛 | 48×48×48 | 实验室方块 8720、玻璃板 635、铁栏杆 324、菌类 2500+ |
| `spore:hospital` | 平原 | 48×48×48 | 平滑石 8382、石英 7684、灰混凝土 5187、**铁栏杆 1178**、染色玻璃 701 |
| `spore:prison` | 丛林 | 48×48×48 | 石砖 8120、裂石砖 5527、石英 3049、**铁栏杆 1600**、藤蔓 930 |
| `spore:military_camp` | 沙漠 | 48×30×48 | 砂岩 12966、沙 9530、铁栏杆 341、腐木 328 |
| `spore:mines` | 寒冷群系 | 48×28×23 | 石头 5385、**实验室方块 497**、实验室台阶 257、蓝冰/浮冰 285 |

注意 `mines` 里混了实验室方块和台阶 —— 它是"实验室体系的矿道"，所以风格介于两者之间。

### 密度靠 structure_set，不靠 rarity_filter

| 结构 | spacing | separation |
|---|---|---|
| `lab` | 32 区块 | 10 区块 |
| `hospital` | 48 | 40（最稀有） |
| `prison` | 32 | 10 |
| `military_camp` | 32 | 10 |
| `mines` | 35 | 25 |

`spacing/separation` 是**按网格均匀撒点**的，所以永远不会在同一视野里堆出好几座。
这正是我们之前用 `rarity_filter`（每区块独立掷骰）导致"一眼四座"的根因 —— 要彻底解决，必须改成 `Structure` + `structure_set`。

### 结论

- ✅ 用户观察正确：不同群系看到的"实验室"确实长得不一样
- ❗ 但机制不是"同一座建筑按群系换皮肤"，而是 **5 座独立建筑各自绑定群系，再用一个标签归为同类**
- 可借鉴点：**用标签组织"同类不同款"的地标**，用 `structure_set` 控制密度
