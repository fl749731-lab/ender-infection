## 护甲、武器和材料

- 护甲：晶壳轻甲、母巢重甲。
- 武器：棱晶长枪、裂地战锤、晶刺弩、共鸣法杖。
- 掉落物：感染组织、菌丝束、晶体碎片、孢子囊、甲壳板、浓缩生物质、共鸣器官、母体核心。
- 材料对应方向：小型单位提供基础组织、菌丝或碎片；特化单位提供甲壳、孢囊或器官；高阶单位提供核心。实际掉率、制作配方和属性需实现时另行确定。

## 转为实际模型时的要求

优先保留各单位的独立轮廓与功能结构。几何和贴图应按原版 16× 的纹素密度简化，不把概念图的每一处高频细节机械转换成小方块。生物和家具保留完整 UV 图集，分别做好身体、四肢、附肢和攻击器官的骨骼；动作与伤害帧同步后，再接入 AI 和特效。
