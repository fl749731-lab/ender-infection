# 研究所全房间陈设与 F7 母体收容舱

本轮只构建和验证 NeoForge Minecraft 1.21.1 / Java 21。沿用仓库共享资源源目录和转换脚本，不修改 NeoForge 的生成目录。

[查看全部 48 间房的 96 张实景](全部房间.md) · [本地预览 JAR](../../dist/institute-rooms-v2/ender-infection-neoforge-1.21.1-0.12.0-alpha.7-rooms-preview.jar) · [原生检查记录](final-native-tests.json)

本地开发预览 JAR 位于 `dist/institute-rooms-v2/`，保留原版本号并加文件名预览后缀，未发布或替换玩家实例。`final-native-tests.json` 记录 69 项通过的原生检查，覆盖剧情保护、母体保存、完整建筑、F8、E8 和裂隙回归。

48 间房均加入了符合用途的成组陈设：科研实验台、医疗观察床、研究办公桌、档案架、宿舍床位、餐桌、种植槽、设备底座和仓储货位。186 组建筑模块含此前的入口和中庭模块；最终保留 48 个补给桶，提供 2645 个真实储物家具。所有原任务控制器、40 处门禁、881 盏受控灯和 42 台加工设备的位置保持不变。全部原有储物家具和战利品配置均保留，比较见 `layout-validation.json`。

13 个新增模块由建筑 MCP 实际制作，源文件在 `tools/institute_architecture/`；可重建脚本为 `tools/create_institute_furnishings_mcp.py`，调用记录为 `mcp-furnishings.json`。模块使用单独的操作面和连通检查，不向剩余空格随机塞柜子。事故房 E8 和 Boss 大厅 F8 的出生点、终端及操作空间受到额外保护。

## F7 最底层母体

F7 污染隔离室新增 9×7 格封闭收容舱和舱外裂隙锚点。相对设施原点，母体脚底为 `[97, 4, 73]`，锚点为 `[103, 5, 73]`；B3 地板为 Y3。

- 自然生成或管理员建造时，模板只保存锚点标记。实际服务器加载完整舱体后才生成一只第二阶段孵化母体，不主动加载其他区块。
- 母体和锚点按 UUID 真实绑定，补能继续使用原有规则：每秒最多把一份母体生物质转为一份锚点能量。初始 64 生物质和 24 锚点能量，有容量与资源上限。
- 舱体完整时，母体保持存活与正常实体状态，暂停孵化、扩张和升级；没有使用 `NoAI` 阻断补能。能量有效时显示连接粒子。
- 打破舱体后解除收容，恢复普通母体行为；读档保留破舱与绑定状态。母体死亡后不重生，重新进入区块也不复制母体。
- 和平难度暂不初生母体；已经处于完整收容舱内的母体不会因切换和平难度消失。
- 原 F8 收容监管体、抑制台和奖励流程保持原位置。

## 剧情中的建筑保护

依据 `ender_infection_colored/NEXT_RELEASE_PLAN.txt` 的研究所探索顺序及底层失控裂隙节点，建筑保护随每所设施的剧情独立保存：

- F8 的剧情裂隙真正出现前，模板原有的墙、地板、玻璃、门和设备不能被玩家破坏，创造模式也遵循同一规则。保护还覆盖爆炸、怪物破坏、活塞搬移及本模组的地形侵蚀；室外保留地形和原模板空气位置不进入保护掩码。
- 修复供电、F7 锚点首次获得能量和 E8 事故都不会解除保护。现有 F8 前置满足、预警结束并实际生成监管体后，裂隙显现，永久解除该设施的建筑保护。暂停战斗、断电和读档不会重新上锁，也不影响其他研究所。
- 当前任务明确要求破坏的目标可在裂隙前单独放行。脚本通过 `InstituteProtection.requireBreakTargets` 按相对坐标和目标方块指定当前目标；多方块设备的部件会解析到同一根。目标完成或任务切换后不保留长期豁免。
- 现有计划没有列出提前必拆的具体方块。E8 维修与 F8 抑制台继续使用已有右键交互，不把普通设备自动认定为可拆目标。
- 新生成建筑的方块实体保存设施偏移，首次加载即可恢复保护；不需要玩家先操作终端。管理员建造时也会主动登记设施。

## 检查与实景

独立结构检查已通过：48 房、56 模板、76 个床半块、2645 个储物家具、178 处常亮光源及 60 处晶体表面补光。`final-native-tests.json` 记录当前原生验收，`native-room-preview.json` 记录实际客户端镜头与图片校验和。

在 NeoForge 工程中可执行：

```text
gradlew.bat runGameTestServer -PmotherChamberChecks
gradlew.bat runGameTestServer -PcentralInstituteChecks
gradlew.bat runClient -ProomVisualCheck -ProomPreviewRooms=all
```

截图采用独立超平坦新世界中当前模板的实际房间，开启真实设施照明；这属于室内视觉检查，不是自然地形生成验收。可用逗号分隔的房间编号选择少量房间，例如 `-ProomPreviewRooms=F7,A3,B6,B7`。旧版截图继续保存在 `previews/institute-architecture-v1/`，不代表本轮全房间结果。
